# Project Agent Instructions

This repository contains a responsive sales dashboard built with HTML, CSS, and JavaScript. Keep the implementation static and lightweight.

## Current app structure
- `index.html` for layout
- `css/styles.css` for styling
- `js/scripts.js` for interactions and charts
- ApexCharts is loaded from a CDN in the browser

## Expectations
- Use minimal, surgical edits.
- Maintain the dark dashboard theme and responsive layout.
- Avoid adding frameworks or package dependencies unless explicitly required.
- Treat the dashboard as a simple static front-end app.

## Validation
- Check the page using Live Server.
- Make sure the sidebar works and the charts render without errors.
