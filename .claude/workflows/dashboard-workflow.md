# Dashboard Workflow

## Goal
Maintain and improve the responsive sales dashboard while preserving the current design and static front-end architecture.

## Workflow
1. Review the current page structure in `index.html`.
2. Check the styling in `css/styles.css` for layout, color, and responsive issues.
3. Review the behavior in `js/scripts.js` for sidebar and chart logic.
4. Make the smallest valid change needed.
5. Verify the result in a browser using Live Server.

## Constraints
- Keep the app framework-free.
- Do not add packages or build tooling unless requested.
- Preserve the existing dark dashboard UI and mobile responsiveness.
- Keep code readable and consistent with the current project style.
