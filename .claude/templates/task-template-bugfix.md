# Bug Fix Task Template

## Issue
Describe the bug or regression.

## Scope
- Investigate the relevant code in `index.html`, `css/styles.css`, and/or `js/scripts.js`.

## Requirements
- Fix the root cause.
- Keep changes minimal and targeted.
- Preserve the app’s current design and behavior.
- Do not introduce new regressions.

## Validation
- Reproduce the issue or identify the failing behavior.
- Verify the fix in the browser after changes are made.
