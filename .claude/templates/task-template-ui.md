# UI Task Template

## Goal
Describe the UI change needed.

## Scope
- Page: `index.html`
- Styles: `css/styles.css`
- JS: only if needed for behavior

## Requirements
- Maintain the current dark dashboard aesthetic.
- Preserve responsiveness and usability.
- Keep changes minimal and consistent with the existing codebase.

## Validation
- Open the page locally with Live Server.
- Confirm the updated UI looks correct and the layout remains stable.
