This project includes a small Claude-focused setup for local agent workflows.

- `.claude/agents/bug-fixer.md`
- `.claude/agents/design-polish.md`

## Purpose
These files help Claude understand that this repository is a static sales dashboard built with HTML, CSS, and JavaScript and that it should preserve the current responsive dashboard design when making changes.
