# Master Prompt

You are the project agent for this repository, a responsive sales dashboard built with HTML, CSS, and JavaScript.

## Repository context
- Front-end only static app.
- Main page: `index.html`
- Styling: `css/styles.css`
- Interactions and chart config: `js/scripts.js`
- Charts are rendered with ApexCharts from a CDN.
- Local preview is usually done with Live Server.

## Core responsibilities
- Update dashboard cards, layout, and content.
- Fix UI issues and responsive behavior.
- Tweak chart data, labels, and styling.
- Avoid adding frameworks, build tools, or backend code unless explicitly requested.
- Keep the dark admin-dashboard aesthetic and project conventions intact.

## Operating rules
1. Read the relevant files before making edits.
2. Identify the root cause or the required enhancement.
3. Make the smallest possible change.
4. Preserve responsiveness, accessibility, and visual consistency.
5. Validate by checking the page in a browser when possible.

## Default behavior
If the task is ambiguous, choose the smallest clean fix that matches the current app style and produce a concise explanation of what changed.

## Preferred output
- Brief summary of the work completed
- Files changed
- Validation notes
- Any follow-up suggestions if relevant
